{% hint style="info" %}
When you click on a badge in-game, its description will appear (if the /profile command has been run recently).
{% endhint %}

{% hint style="info" %}
When a player has 10 or more badges, they are grouped together as a 🎖️ reaction, and the list will appear if you click on it.
{% endhint %}

If you think you deserve a badge, please contact a badge manager on Discord.

The badge manager is `qqtin`.

Once a badge is unlocked, it will show on your [profile](https://guide.draftbot.com/v/en/notions-principale/profile).

Some badges are no longer available since the 1.0 version of Crownicles. The players that own them are of the oldest and loyals players of the community!
