# Writing / Translation of the guide

We use [GitBook ](https://github.com/DraftBot-A-Discord-Adventure/DraftBot)exclusively for writing the guide (pull requests to the guide’s GitHub repository will not be considered).

As it mainly a french server, everything followings are in french.

All the necessary information is available via the bot’s [Discord server](https://discord.com/invite/AP3Wmzb). You will need to go to the #infos-grades channel and request the @Wiki role. This will give you access to the #wiki channel, where all information relating to the guide and its writing is discussed.

The link to access the GitBook project and start suggesting improvements is pinned in the #wiki channel.

To make a change request, go to [Gitbook](https://app.gitbook.com/o/-MH1_FERaV0tsl55ERgC/home), choose the corresping category (Crownicles guide/english), clicking on "Edit" (in the top right corner) create a version where you can make every wanted changes then you can request a review (top right corner too) and ping `@bananeplantain_` in the #wiki channel for a review. When the change request is validated, it merged in primary content.

If you plan to make changes, consider looking at the french version for informations and visual layouts.&#x20;
