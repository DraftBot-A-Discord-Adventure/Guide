# Navigate through the Wiki

When reading this wiki, you may encounter tags at the top of the page, here are their meanings

* "Old/alpha's bot images" : the page contains images from the test bot or are been taken before the bot's name change.
* "Lightly outdated content" : the feature is still pretty the same but a part of the page have received changes/is no longer true.
* "Heavily outdated content" : the feature has received significants changes and most of it is false.
* "Work in progress" : the page is empty/missing a part of the informations.&#x20;
* "Missing things from fr" : things availables on the french version but not here, could be lesser importance informations or visual improvements.
